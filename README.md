# Dulce a tu ritmo

PWA de recetas dulces con raciones ajustables, ingredientes marcables,
temporizadores y funcionamiento sin conexión.

## Recetas

- Flan de nata: receta propia, validada por el propietario el 15 de septiembre
  de 2026 con resultado satisfactorio. Las cantidades concretas utilizadas y
  las observaciones detalladas quedan pendientes de registrar.
- Tarta de quesillo: receta preparada para la siguiente prueba real; todavía no
  validada.
- Rollos de canela con chocolate: adaptación redactada a partir de la
  [publicación de @reposteriacasera_7](https://www.instagram.com/p/DdRYl-1DBY_/),
  consultada el 15 de septiembre de 2026. No reutiliza el vídeo, las fotografías
  ni la redacción original. Sus tres imágenes orientativas son originales,
  generadas para la PWA y están identificadas como tales. Requiere una prueba
  real antes de considerarse validada.
- Tarta de queso con chocolate Fusión Maracuyá: receta de tres ingredientes
  incorporada a partir del [reel de Alex Seblanc](https://www.instagram.com/reel/DakgO77tWan/).
  El reel no especifica las dimensiones del molde.
- Tarta de almendra y naranja: receta naturalmente sin gluten para molde de
  22 cm, con almendra molida, naranja fresca y canela.
- Tarta Ferrero de chocolate y avellanas: bizcocho de cacao en tres capas,
  crema de mascarpone y Nutella, avellanas tostadas y ganache de chocolate.

El repositorio conserva el nombre técnico `flan-pwa` para no romper la URL
instalada. Cambiar el nombre del repositorio se evaluará por separado.
